# Flutter App Development Bootcamp

A collection of educational mobile applications built during **The App Brewery's Flutter Development Bootcamp**.

## Projects
- **Ambitious App** — introductory Flutter application
- **Business Card** — personal profile UI
- **Dicee** — dice rolling app
- **Magic 8 Ball** — random answer generator
- **Xylophone** — musical instrument app
- **Quizzler** — quiz application
- **Destini** — interactive story
- **BMI Calculator** — body mass index calculator
- **Clima** — weather application
